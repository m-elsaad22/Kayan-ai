إضافة ووردبريس واحدة تجمع التتبع التجاري وتوليد مقالات حصرية بالذكاء الاصطناعي.

== Description ==

تجمع هذه الإضافة مميزات:
* Kayan Track Pro (تتبع، DNI، احتيال، Heatmap، تقارير)
* Rukn Smart AI و Rukn AI (SEO، Schema، ترجمة، ربط، منافسين، تحويل)
* مستورد CSV
* مولّد مقالات حصري بالذكاء الاصطناعي بدون قوالب ثابتة

كل مقال يُولَّد بزاوية وشخصية وهيكل مختلف، ثم يُقاس تشابهه مع مقالات الموقع السابقة.

== Installation ==

1. ارفع مجلد `rukn-kayan-suite` إلى `/wp-content/plugins/`
2. فعّل الإضافة
3. ادخل مفتاح Gemini أو Claude من الإعدادات
4. املأ اسم الشركة والهاتف والواتساب
